# Cabinet diffraction diagnostics

This small console diagnostic links the production cabinet source and uses the existing Hare assembly and MathNet package. It does not load Rhino or change the Universal library's target frameworks. It needs .NET 8 and a built Hare assembly (override `HareAssembly` if needed).

From this directory:

```powershell
dotnet restore --source "$env:USERPROFILE\.nuget\packages"
dotnet run --no-restore -- C:\path\to\diagnostic-output
```

Omit the output argument to write CSVs under the system temporary directory. `polar.csv` contains 0.5-degree cuts in four azimuth planes at depths 0.10, 0.25 and 0.50 m; `depth.csv` sweeps 0.05 through 0.55 m at side/oblique/rear angles. Both cover all eight octave bands, use a 0.32 x 0.80 m cabinet, a 0.13 m piston, an offset driver (0.03, 0, 0.17) m and a fixed 20 m receiver distance. Magnitudes are multiplied by distance; these are absolute pressure comparisons, without per-curve normalization.

Checks include saved direct/front complex values from the original working implementation, front-field invariance with depth, absent driven edges at zero depth, four longitudinal edges with two incident-face channels each, nonzero complex depth contributions, separate third/fourth-order contributions, centered-cabinet reflection symmetry, grazing-angle convergence, depth-subdivision seams, public octave clamping and the unchanged 8 x 72 x 37 balloon string layout.

For a one-time comparison of complex rear-edge driving pressures, save the previous source outside the repository and rename its class and constructor to `Legacy_Cabinet_Diffraction`. Then run:

```powershell
dotnet run --no-restore -p:BaselineSource=C:\path\to\Legacy.cs -- C:\path\to\diagnostic-output
```

The extension is a distributed-edge approximation through fourth order. The second-order field seeds a shared-face transfer operator. That operator is applied to the previous order only, then each new order is added coherently to the result; applying it to the accumulated field would double-count shorter paths. Rear -> depth and depth -> rear/depth couplings connect distinct physical edges along exterior cabinet faces. A depth dipole emits across the other adjoining face from the one that drove it. Co-located channels on the same physical depth edge never couple to each other. The matrix is built once per octave/driver, then reused for the two higher-order updates. Each depth edge is driven separately from its two adjoining front edges; its signed dipole axis is the outward normal of the incident side face. Exterior radiation uses the union of the adjoining face tapers. The cubic taper spans direction cosines -0.1 to +0.1, approximately +/-5.7 degrees about grazing. The second-order rear-edge incident strength is unchanged, while its former hard visibility switch is replaced by this taper.

True point-vertex diffraction and calibrated wedge coefficients are not included. The new finite-edge interactions include neighborhoods where rear and depth edges meet, but that is not a separate trihedral vertex coefficient or a vertex shadow-boundary correction. These higher-order paths are a DED approximation, not a complete all-path BTMS expansion. Midpoint subdivision changes produce small quadrature jumps; they are measured rather than assumed absent. The inherited rear-edge model is not a thin-cabinet limiting solution: zero depth disables higher orders, and depths far smaller than the element spacing can under-resolve front/rear coupling. The diagnostic sweeps establish behavior for the stated dimensions and depths, not general physical validation against measurements.

New Rhino column sources use the DED model labels. Already stored balloon strings are not regenerated by this code change; recreate those sources to calculate their new balloons.
The [vertex diffraction reference check](VertexDiffraction.md) records the canonical acoustic formulation, the new restricted spherical coefficient solver and its diagnostics, and the selectable experimental front-corner correction, its engineering assumptions and remaining transition matching.

## Choosing a cabinet model

`Pach_Column_Array_Source` now has a `Diffraction` list: `Vanderkooy` (the existing default), `NumericalHybrid` (experimental), and `TrihedralExperimental` (experimental front-corner correction). The selected model is recorded in the existing `ArrayCabinetDiffraction` user string. Existing stored balloons are unchanged; recreate a column to select another model. All drivers' balloons are calculated before any document objects are created, so numerical failure does not leave a partial array.

Universal provides `ICabinet_Diffraction`, implemented by `Cabinet_Diffraction`, `Cabinet_Diffraction_Numerical` and `Cabinet_Diffraction_Trihedral`. All three retain `Pressure` and `Driver_Balloon`. The original constructor and DED field formulas are unchanged. All three implementations use the same full-sphere sampling, normalization and string encoder.

The numerical model solves an exterior Neumann radiation problem for a rigid rectangular cabinet and a flush circular piston with uniform velocity. It uses interior fundamental sources and a boundary-integral projection, with MathNet Gauss-Legendre quadrature and a cached complex LU factorization per octave. Source matrices are shared by all drivers in the same cabinet. The default method uses MFS through 500 Hz, a coherent 50/50 MFS/DED blend at 1 kHz, and the existing DED field from 2 kHz upward. These continuation weights span 500 Hz to 2 kHz on the octave/log-frequency grid. This is a separate whole-cabinet field, including the approximation of edge and corner interactions; it does not add a trihedral point coefficient to DED or enumerate diffraction orders.

The method follows the interior-source approach described by [Candy, JAES 61(6), 356-365 (2013)](https://www.researchgate.net/publication/286063378_Accurate_Calculation_of_Radiation_and_Diffraction_from_Loudspeaker_Enclosures_at_Low_Frequency). The implementation is independent and has not reproduced all of that paper's benchmarks. Its high-frequency continuation reuses our existing DED method rather than the paper's high-frequency formula.

The default source resolution is four samples per wavelength with a minimum long-axis subdivision. The optional `samplesPerWavelength` constructor argument (3-8) permits refinement. Sources lie on a box inset by 15% of each cabinet dimension. Positive dimensions and a piston that fits on the front baffle are required. A 2048-source limit and a 16-million-entry limit for each boundary projection matrix reject oversized calculations before allocation. The solver checks its algebraic residual and rejects nonfinite solutions. These checks do not establish physical convergence or protect against every ill-conditioned geometry.

Run the numerical diagnostics separately:

```powershell
dotnet run --no-restore -- --numerical C:\path\to\numerical-output
```

They explicitly disable continuation to diagnose raw MFS, and separately check the selected hybrid and exact complex continuation weights. They check the compact-cabinet monopole limit, derivative phase/sign, reflection symmetry, grazing continuity, coarse/default/refined complex far-field cuts, low-band off-grid wall-flux refinement, depth-subdivision seams, the default column's central/end drivers, input limits and balloon strings. CSVs compare numerical and DED fields for the same cabinet and sweep numerical side/rear response with depth.

On the 0.08 x 0.16 x 0.10 m diagnostic cabinet, default-to-refined complex angular RMS changes were 0.95-5.08% across the eight bands. The compact-cube distance-scaled low-frequency pressure was 0.5020, against the monopole limit of 0.5. Tested grazing changes were below 2e-7 of unit pressure. The largest tested depth source-count seam was 0.01073 of unit pressure: discretization changes are small but not continuous.

The raw high-frequency MFS depth sweep also showed a sharp 4 kHz dip that changed substantially with refinement, plus other high-band sensitivity. This is why raw MFS is excluded from the selected hybrid above 1 kHz. Passing an algebraic residual and one angular refinement comparison did not detect these errors. Setting the new constructor's optional `highFrequencyContinuation` argument to `false` exposes raw MFS for research diagnostics only; it is not a Rhino menu choice.

Near-field accuracy remains unresolved. At one off-grid rigid-wall point, default normal-flux errors were 2.5-6.9% of the piston flux; refinement reduced the low-band errors to 2.3-3.4%, but the refined 8 kHz result was 15.1%. Far-field agreement does not validate surface pressure, corner singularities, or a canonical vertex coefficient. Use this experimental model for comparison of far-field balloons, with further convergence checks for other dimensions. No measurement comparison, deformable walls, ports, or mutual mechanical/acoustic driver loading is included. Stored balloons retain the existing magnitude-only, per-octave normalization workflow; the complex field is available through `Pressure`.
The selected hybrid's largest tested depth subdivision seam was 0.00122 of unit reference pressure (0.12%). All eight original DED balloon strings were also compared byte-for-byte against the saved pre-selection build and were identical. Both Rhino target frameworks build; the command-line choice has not been exercised inside a running Rhino session. Build outputs used isolated folders because Rhino already had the normal plugin outputs loaded.
